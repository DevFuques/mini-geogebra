# 📊 Mini-GeoGebra Acadêmico - Cálculo 1

Aplicação web interativa desenvolvida como trabalho prático da faculdade para visualização e análise de funções, limites, derivadas, pontos de máximo/mínimo e otimização, aplicando os conceitos fundamentais de Cálculo 1.

## 🚀 Tecnologias Utilizadas
- **HTML5 & Tailwind CSS** (Interface e Estilização)
- **JavaScript (Vanilla)** (Lógica da aplicação)
- **Math.js** (Processamento matemático e simbólico)
- **Function Plot / Plotly.js** (Renderização gráfica)

## 👥 Equipe
Projeto desenvolvido pela equipe de Desenvolvimento para a disciplina de Cálculo 1.
